# ELO Measurement Log

Every strength measurement this project has taken, newest last. `Run-EloMatch.ps1` appends one row
per run, so **the local table stays at the end of this file**.

**How any of this is measured, and how to read a row, is in
[`EloMeasurement.md`](EloMeasurement.md)** — the pinned setup, the interpretation guide, and the
SPRT-versus-fixed-batch decision. Nothing here restates it.

**A row is only ever read against other rows in its own table.** Different instruments and different
references are not on a common scale, so the tables are kept apart rather than annotated.

**Node counts and nps quoted in rows before 2026-08-16 are main-tree only.** Until #312 the engine
counted `pvs()` nodes and never `quiescence()` nodes, so any node count or nps in an earlier row
excludes every move searched inside quiescence — 12.1% of the true total on the bench suite at the
time of the fix, which understated nps by 13.8%.
Two consequences when reading old rows: an nps figure is not comparable with one taken after #312,
and a change that moved work between the main tree and the quiescence tree could show an nps
collapse with no real slowdown, or the reverse. **Wall clock was never affected** and is the figure
to trust in an older row. Where a row quotes a "derived" time-to-depth, it was computed as
`nodes / nps` from two different runs and is unreliable; measure the clock directly instead.
